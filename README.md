# Basketball Rebounds — A Monte Carlo Study

A website presenting a computational study of basketball rebound patterns.

## Project structure

- index.html: main webpage
- css/style.css: visual design
- js/main.js: angle selector
- assets/images/: exported plots and figures
- assets/videos/: rendered MP4 animations
- data/: CSV files and numerical summaries

## Run locally

Open index.html in a browser, or run:

    python3 -m http.server 8000

Then visit http://localhost:8000.

## Scientific note

The website distinguishes measured simulation results from
hypotheses and empirical rules of thumb.
